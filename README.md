# 广东财贸职业学院抢课助手

广东财贸职业学院 · 抢课系统最终版 —— Windows 桌面选课工具（单文件版）。

## 目录说明

| 文件 / 文件夹 | 用途 |
| --- | --- |
| `抢课助手/` | 主程序，双击里面的 exe 即可运行 |
| `激活码生成器/` | 开发者专用，用来生成给学生/同学的激活码 |
| `使用说明.txt` | 完整使用说明 |

## 快速开始

1. 双击 `抢课助手/` 里的 exe 打开程序。
2. 首次打开会解压内部文件，约 5～10 秒，属正常现象。
3. 填学号 + 激活码，点「验证并进入」。
4. 填登录密码（学号自动填好），填 1 个课程号。
5. 点「自动登录」，进入选课页后自动开始抢课。
6. 想中途停止，点红色「停止抢课」按钮。

## 生成激活码（仅开发者）

1. 双击 `激活码生成器.exe`。
2. 填学号、学期、到期日期（格式 `YYYY-MM-DD`）。
3. 点「生成激活码」，再点「复制」发给对应同学。

注意：
- 学号必须和同学实际登录的学号一致，否则激活不通过。
- 学期默认 `2026-FALL`，学校学期变了要改。
- 到期日期过了，激活码自动失效。

## 重要提醒

- **私钥（`private_key.pem`）不要上传、不要发给任何人。** 丢失或泄露会导致激活码体系失效，请本地妥善备份。
- 主程序 exe 体积较大（约 180 MB），超过 GitHub 单文件 100 MB 限制，建议用 Git LFS 或 GitHub Releases 分发。
