# 广东财贸职业学院抢课助手

广东财贸职业学院 · 抢课系统最终版 —— Windows 桌面选课工具（单文件版）。

## 仓库内容

| 文件 | 用途 |
| --- | --- |
| `使用说明.txt` | 完整使用说明 |
| `.gitignore` | 忽略私钥/压缩包等敏感文件 |
| Releases → v1.0.0 | 激活码生成器.exe（开发者用） |

主程序 exe（约 180 MB）超过 GitHub 网页上传限制，未包含在本仓库中，通过网盘或私发分发给同学。

## 快速开始

1. 拿到主程序 exe，双击打开，首次解压约 5～10 秒属正常。
2. 填学号 + 激活码，点「验证并进入」。
3. 填登录密码、课程号，点「自动登录」自动抢课。
4. 想停止点红色「停止抢课」按钮。

## 生成激活码（仅开发者）

1. 到本仓库 Releases 下载「激活码生成器.exe」。
2. 填学号、学期、到期日期（格式 YYYY-MM-DD），生成并复制激活码发给同学。
3. 私钥（private_key.pem）必须和生成器放一起，且绝不外发。

## 重要提醒

- 学号必须和同学实际登录学号一致，否则激活不通过。
- 学期默认 2026-FALL，学校学期变了要改。
- 到期日期过了，激活码自动失效。
- **私钥（private_key.pem）绝不上传、不外发**，丢失或泄露会导致激活码体系失效，请本地妥善备份。
