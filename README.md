# 广东财贸职业学院抢课助手

广东财贸职业学院 · 抢课系统最终版 —— Windows 桌面选课工具（单文件版）。

## 快速开始

1. 双击主程序 exe 打开，首次解压约 5～10 秒属正常。
2. 填学号 + 激活码，点「验证并进入」。
3. 填登录密码、课程号，点「自动登录」自动抢课。
4. 想停止点红色「停止抢课」按钮。

## 生成激活码（仅开发者）

用「激活码生成器.exe」填学号、学期、到期日期生成激活码。

## 重要提醒

- 私钥（private_key.pem）绝不上传、不外发，请本地备份。
- 主程序 exe（约 180 MB）超过 GitHub 100 MB 限制，请到 Releases 下载。
